# Stuctured CSV REST API Connector
This connector allows you to place CSV files under the resources directory and have them seen as a data source for BigID. This connector also supports SAR functionality. 


### Usage

Running the service
```
$ npm start
```

If you don't care to run it locally and just want to see it working or use it as a demo of custom REST functionality, it is always up at https://rest-api.apps.mybigid.com/
